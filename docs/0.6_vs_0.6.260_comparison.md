## Key Code Differences by File

### Hand.cpp (562 lines different)

#### Selection Method

| Aspect | Current (v0.6) | Backup (v0.6.260) |
|--------|----------------|-------------------|
| **Primary method** | Custom raycast + `GetObjectsInRadius()` | **ViewCaster-only** via `heisenberg::GetPrimaryWandTarget()` / `GetSecondaryWandTarget()` |
| **Frame skipping** | Yes (2-6 frames dynamic) | **No frame skip** - runs every frame |
| **Leeway time** | 0.25s grace period before clearing | **No leeway** - immediate clear when ViewCaster clears |
| **State transition logging** | Includes distance in log | No distance (ViewCaster handles range) |

#### Selection Code Comparison

**Current v0.6 (lines 209-240):**
```cpp
// OPTIMIZATION: Dynamic frame skipping based on hand movement
++_selectionFrameCounter;
float distMovedSq = dx * dx + dy * dy + dz * dz;
bool handMoved = distMovedSq >= kPositionCacheThreshold * kPositionCacheThreshold;
int effectiveFrameSkip = handMoved ? 2 : kSelectionFrameSkip;  // 2 frames when moving, 6+ when still

if (_state == State::Idle && !_selection.IsValid() &&
    _selectionFrameCounter < effectiveFrameSkip) {
    return;  // Skip this frame
}

// HIGGS-style selection: Use directional raycast (what you're pointing at)
if (FindSelectionRaycast()) {
    _lastSelectionTime = Utils::GetTime();
}
```

**Backup v0.6.260 (lines 215-272):**
```cpp
// VIEWCASTER-ONLY SELECTION (January 2026)
// Selection is ONLY valid when the native ViewCaster populates a target.
// No fallbacks, no range checks (game already handles pointing/range).

RE::TESObjectREFR* viewCasterTarget = _isLeft ? 
    heisenberg::GetPrimaryWandTarget() : heisenberg::GetSecondaryWandTarget();

if (viewCasterTarget) {
    if (!viewCasterTarget->IsDeleted() && 
        !viewCasterTarget->IsDisabled() &&

        _selection.SetRefr(viewCasterTarget);
        // ... set selection properties

    }
}

// No valid ViewCaster target - clear selection immediately
if (_selection.IsValid()) {
    _selection.Clear();
}
```

## Summary: What Was Added in 0.6.260

1. **ViewCaster-Only Selection** - Replaced custom raycast with native game ViewCaster
2. **No Frame Skipping** - Selection runs every frame for responsiveness
3. **No Leeway Time** - Immediate state transitions (caused issues - see below)
4. **Native Havok Queries** - Enabled with correct vtable addresses
5. **Event-Based CrosshairTarget** - Uses `PickRefUpdateEvent` subscription
6. **Additional Features:**
   - Contact impulse listener for hand collision
   - Finger collision detection
   - Pipboy/tape deck interaction
   - Virtual Holsters integration
   - Water interaction effects
   - HUD rollover control

## Known Issues in 0.6.260

1. **Selection Flickering** - Without leeway time, ViewCaster flicker causes grip to fail
2. **Crash on Grab** - `PlayerCharacter::AddNote` crash (unrelated to selection changes)
3. **Cannot Reselect After Release** - ViewCaster clears too aggressively

## Recommendation

To restore 0.6.260 functionality:
1. Copy all missing files from backup to src
2. Merge the ViewCaster selection code from Hand.cpp
3. Update Physics.cpp with correct vtable addresses
4. Consider adding minimal leeway time (0.1-0.15s) to prevent selection flickering
